全部清单 row：件数 / 类数 / 重量 / 价值

现状四个数字分在三处、三种字号：重量在标题右边（16 粗等宽），价值在第二行右边（11.5 等宽），件数类数和描述挤在第二行左边。下面三个方案都保留缩略图条，只重排数字。

怎么选

  • A 一条指标线：重量放大领头，后面价值、件数、类数用同一字号顺排，描述单独一行、没有就不占位。改动小、信息顺序清楚（重量最重要），行高和现在差不多。
  • B 右栏数字：四个数全部右对齐竖排，标题、描述、图条在左侧。竖着扫能直接比重量；代价是右栏吃掉宽度，窄屏下图条只能放 4~5 格。
  • C 指标格：小标签在上、数值在下，四项一眼看懂是什么，没有底色和分割线，只靠留白分组。最“仪表”，但每行高约 20pt，一屏少一条左右。
  • D 图条尾注：标题行只留名字和重量，件数类数与价值收到图条右侧两行小字——图条本来就在讲“装了什么”，件数挨着它最自然。改动最小，但价值存在感最弱。
  • 任何方案都可以加：按重量或价值排序时，那个值用 accent 色，提示当前排序键。
