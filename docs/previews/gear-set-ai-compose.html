要点

  • 只是草稿。AI 结果只填进编辑页，不写数据库；取消编辑就什么都不留下。
  • 缺项默认勾选。创建时勾选的缺项会成为 owned = false 的待购装备挂进清单，没勾的直接丢弃，不进装备库。
  • 理由一句话。每个缺项写明为什么需要，方便用户判断是借、是买，还是不带。
  • 重新搭配会保留用户手动增删过的装备，只重算其余部分。
  • 「AI 选」只是淡色小字，用户改过数量或携带方式就去掉；保存后不再显示。
  • 编辑已有清单也显示这个入口，但只补充，不移除用户已经选的装备。
