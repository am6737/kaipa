清单页 row：件数 / 类数 / 重量 / 价值 怎么排

现在四类数字分散在三个基线上——重量在标题右侧、价值在第二行右侧、件数类数和描述挤在第二行左侧， 所以竖着扫的时候眼睛要来回跳，宽度一紧就被 ellipsis 吃掉。下面四个方案都保留「缩略图条」这个识别物，只是重新分配对齐关系。

怎么选

  • A 数值右栏：改动最小，直接沿用装备库 ItemRow 的「重量在上、价值在下」右栏，两个清单页竖着扫时数字在同一列。代价是件数/类数仍留在左下，一行的信息重心还是两段。
  • B 图标元数据单行：四项放到同一条基线，用极小图标区分含义，数字用等宽字体对齐；描述单独一行、只在有时出现。行高最矮、最干净，但数字不再成列，靠图标逐个识别。
  • C 四格统计条：像仪表，label 在上、值在下，四格等宽，最能看懂「这是什么数字」，也最容易日后加「最重件」「体积」。代价是每行高约 28pt，一屏少一到两条，密集列表会显得笨。
  • D 缩略图前置：把 6 格图条压成左侧 2×2 小方块当行首图标，标题/描述/件数类数走满整行宽度，数字仍然右栏。行高和装备库一致，整页节奏统一；代价是单件照片识别度下降。
  • 如果按「重量」或「价值」排序，右栏那个值可以用 accent 强调一下，让用户知道当前排序键——四个方案都能加。
  • 中文界面里件数与类数之间用空格分隔（18 件 6 类），不加 ·。
