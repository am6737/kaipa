旅程详情 v3：克制版

功能和 v2 一样，只是没问题的时候不出现，没到时候的不出现，重复的只留一处。示例还是武功山三天穿越，四人同行，林是发起人。手机屏内可以上下滚动。

一页只回答一个问题出发前：还差什么。进行中：来得及吗。结束后：这一趟怎么样。
没问题就不出声完成的事直接消失，不打绿勾。橙色只留给真实的风险。
到时候才出现离出发越近，待办越具体；没有预报就不画天气。
一件事只说一次距离在轨迹里，日落在天气里，分享在右上角，底部不再重复。

v2 到 v3 改了什么

地方v2v3
出发前总览8 块：准备项、集合、计划概览、天气、路线近况、轨迹、简介、版本记录4 块：现状、待办、每天、轨迹
待办5 条，每条带彩色圆点，完成的打绿勾只列没完成的，最多 3 条，按离出发的天数出现；全部完成剩一句话
天气独立的三格卡片合进每天一行，灰色线条图标；没有预报就不画
路线近况独立一块，两条评论加照片只有风险，挂在对应那一天下面
标题下面日期、距离、爬升、头像日期和头像
进行中三个大数字、提醒框、接下来、天气、报备一句折返时间，接下来两处，有预警才显示天气
结束后三个对比数字、海拔叠线、故事卡片、装备清单、同行照片和轨迹，一句话总结，一行装备复盘
底部按钮「发给同行」「继续徒步 已走 6.9 km」，卡片和底部重复分享只在右上角，按钮文字只写动作
装饰每块都有「详情 ›」，到处是圆形图标和彩色标签整行可点，图标和颜色只留给风险
