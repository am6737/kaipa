我的装备 row：重量 / 价值 / 数量 / 分类 / 状态

现状：右栏重量和价值上下贴得很紧（间距 4），名称下面的元信息（分类、数量、状态）和右栏各自一套字号，行与行之间只靠 8pt 内边距分开。下面三个方案都保留缩略图。

怎么选

  • A 数字行（和清单页一致）：名称下面一行「重量 ¥价值 ×数量」，分类和状态标签再放下一行，右栏取消。和全部清单页完全同一套读法，名称能用满整行宽；代价是行变高，原来靠右栏纵向比较重量的习惯没了。
  • B 保留右栏，只拉开间距：结构不变，行内边距 8→12，右栏重量/价值间距 4→4 之外加大行高，分类/标签与名称拉开。最稳，改动最小，竖着比重量仍然顺手。
  • C 右栏重量，价值挪到元信息行：右栏只留一个大号重量，价值和分类、数量并排放进名称下面一行。右栏更干净，重量依旧成列；价值不再单独成列。
  • 三个方案里「待购」装备的重量和价值都显示 —，缩略图为虚线框，和现在一致。
